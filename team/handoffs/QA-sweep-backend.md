Right now the live API on :8001 says `pre_quali` and `stale=false`. UTC is already Oct 24, so the 120 s quali-day TTL is in effect. The API doesn't need the CLI run: it fetches qualifying itself and switches within about 2 min of Jolpica publishing. The CLI run writes the CSV that the stale fallback uses. If Jolpica hasn't published yet, `--mode grid` exits cleanly with a message. **The happy path works.** The risks are below.
