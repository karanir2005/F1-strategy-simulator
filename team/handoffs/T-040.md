# T-040 predictor config changes (backend-engineer)

## What changed (`backend/app/core/predictor.py`, each behind a flag)
1. `blend_win_grid: float | None = 0.0`: grid-mode p_win is model only. Podium/top10/exp_pos keep 0.75/0.25. `None` restores the old behaviour. Pre-quali unchanged.
2. `stick_prequali: bool = False`: stickiness (stick_mode="pole", gamma 4) now applies in grid mode only. Pre-quali refits level 2 with gamma 0 (predict_race, walk_forward, quali_walk_forward). `True` restores T-037.
3. `dnf_exclude_dns: bool = True`: rows with status in `DNS_STATUS` ("Did not start", "Withdrew", "Did not qualify", "DNQ", "Excluded", "Did not participate") are dropped from the DNF fit. Only "Did not start" (16) and "Withdrew" (3) occur in the data. Lap-1 "Retired" with 0 laps (31 rows) did start and stays a DNF.

Tests: fixed `test_blend_keeps_sums...` (pins `blend_win_grid=None`), added `test_t040_grid_win_model_only_and_dns_excluded`. Full pytest: **350 passed**. No API/schema changes.
